# Scadenze — webapp (solo interfaccia)

Interfaccia web per gestire abbonamenti e mutui. **Non contiene dati**: legge e
scrive il file `dati.json` nel repo **privato** `scadenze` tramite l'API di
GitHub, usando un token che inserisci nelle ⚙️ Impostazioni (resta solo nel
browser).

Per questo questo repo può stare su **GitHub Pages pubblica** senza esporre
nulla di personale: gli importi vivono nel repo privato.

- Codice e logica: vedi il repo **`scadenze`** (privato) — `README.md` e `ATTIVAZIONE.md`.
- Al primo avvio: ⚙️ Impostazioni → utente `zenogovoni-art`, repository **`scadenze`**, incolla il token.
